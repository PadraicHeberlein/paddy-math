### PADDY MATH LIBRARY BLUEPRINT
## Low Level Specifications
I want this to be a fast, efficient and versatile math library that can be used for a variety of purposes. From 8 bit microcontrollers to 64 bit supercomputers. It should be written in C++20 and should use modern C++ features. It should be able to run on both x86 and ARM architectures, as well as RISC-V, MIPS, Intel architectures (others?). It should be able to run on both 32-bit and 64-bit architectures. It should be able to run on both little-endian and big-endian architectures. There will be a an evolving set of functions accessible through a C interface, and a C++ interface. These interfaces will intelegently access assembly files to optamize performance picking the optamal assembly file for the architecture.

## High Level Specifications
For the Trancendental functions, I want them to be implemented using the Taylor series expansion interms of its input as a vector space. In than way the operations of powers and division by scalar will allow the same implementation of of (x^n)/n! for real numbers, complex numbers, and matrices.
